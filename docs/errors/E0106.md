# E0106: invalid escape sequence

Inside a string or a character literal, a backslash starts an escape sequence. The valid ones are
`\n`, `\t`, `\r`, `\\`, `\'`, `\"`, `\0`, `\$` and `\u{...}` with one to six hexadecimal digits
that name a Unicode scalar value. Anything else after a backslash is an error.

The compiler marks the backslash and the character after it (or the whole `\u{...}` that is not
valid) and goes on after them.

Strings and characters cannot be used in expressions yet, so, for now, `ki check` also reports
E0201 for the literal of each example below as a whole, besides the mistake inside it. The fences
that say `also=E0201` are the sign of that: when the compiler reads strings and characters in
expressions, those words and this paragraph go away.

## Erroneous example

```ki erroneous also=E0201
fn main() { print("a\qb") }
```

`\q` is not an escape. To write a backslash, double it: the compiler suggests that and offers the edit, which turns `\q` into `\\q`.

## Corrected

```ki corrected also=E0201
fn main() { print("a\\qb") }
```

The doubled backslash is one backslash in the string, followed by the letter `q`.
