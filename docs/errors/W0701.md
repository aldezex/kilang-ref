# W0701: unreachable pattern

An arm of a `match` is tried only for the values that the arms above it did not take, so an arm whose
values are all taken above it can never run. It is probably a mistake: a pattern repeated by accident, a
`_` that is not last, an arm that was meant for another constructor. It is a warning and not an error,
because the program is correct, so `ki check` prints it and still exits with 0 if nothing else is wrong.
`ki run` and `ki emit` do not print it.

The primary label is on the pattern, ``covered by the arms above``. The help says to remove the arm,
and when the arm is on one line the compiler offers the edit that does, with the `;` that follows it if
there is one. An arm that goes over several lines has only the help.

The compiler looks for these arms with what is left of the budget of the check (E0707), so the warning is a
favour and not a promise: a `match` with arms too many to compare one by one has the warnings up to the arm
where the search stopped, and no error. A `match` in which the parser found a mistake in one of the arms is not
looked at (see E0701).

Only a whole arm is reported. An alternative of an or-pattern that the others make useless, `A | B | A`,
is not: the arm matches values that nothing above matches, and which of its alternatives does it is not
something the pattern is made to say. An arm with a guard is checked like any other: it is unreachable if
the arms above it, which have no guard, cover its pattern. A guard never makes an arm unreachable, and an
arm with one never makes another unreachable.

## Erroneous example

```ki erroneous
fn sign(n: Int) -> Int {
  match n {
    0 => 0
    _ => 1
    1 => 2
  }
}
fn main() {}
```

`_` takes every number that `0` does not, so `1` can never be reached. The warning is on `1`.

## Corrected

```ki corrected
fn sign(n: Int) -> Int {
  match n {
    0 => 0
    1 => 2
    _ => 1
  }
}
fn main() {}
```

## Erroneous example

```ki erroneous
type Shape { Circle(Float), Rect(Float, Float) }
fn area(s: Shape) -> Float {
  match s {
    Circle(r) => r * r
    Rect(w, h) => w * h
    Circle(_) => 0.0
  }
}
fn main() {}
```

The third arm repeats the first: `Circle(_)` takes the same values as `Circle(r)`.

## Corrected

```ki corrected
type Shape { Circle(Float), Rect(Float, Float) }
fn area(s: Shape) -> Float {
  match s {
    Circle(r) => r * r
    Rect(w, h) => w * h
  }
}
fn main() {}
```
