# E0302: <name> is defined more than once

Two top-level functions of the same module have the same name. A use of the name stands for the
first one, and the second is an error. The compiler points at the second definition and, as a
secondary label, at the first.

Which of the two stays is not for the compiler to say, so it suggests renaming one or deleting the
second and offers no edit.

## Erroneous example

```ki erroneous
fn f() {}
fn f() {}
fn main() { f() }
```

The second `f` is the mistake.

## Corrected

```ki corrected
fn f() {}
fn g() {}
fn main() { f() }
```
