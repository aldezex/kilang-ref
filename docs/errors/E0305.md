# E0305: unknown attribute

An attribute is written between `#[` and `]` before a function. Ki knows one attribute so far,
`extern`, and only the standard library may write it (E0304), so a program cannot use an attribute
yet: any attribute in it is an error. The list will grow with `derive` and `test`.

The compiler suggests removing the attribute and, for an attribute on one line, offers that edit.
In the standard library, where `extern` is allowed, a name close to it also gets the question
whether `extern` was meant, and the edit that writes it.

## Erroneous example

```ki erroneous
#[inline]
fn f() {}
fn main() { f() }
```

`inline` is not an attribute Ki knows.

## Corrected

```ki corrected
fn f() {}
fn main() { f() }
```
