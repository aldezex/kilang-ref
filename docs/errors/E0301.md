# E0301: unknown name

A name is used that no definition, parameter or `let` in scope provides. Ki looks a name up
in the innermost scope first, then in the enclosing scopes, then among the top-level
definitions of the module and the public names of the prelude. A `let` is visible only
after its own statement, so it cannot name itself in its initializer.

A function whose signature has a syntax error still counts as defined: a call to it is not
reported here, because the compiler has already reported the error in the signature.

## Erroneous example

```ki erroneous
fn main() { prnt(1) }
```

`prnt` is not defined anywhere, so the name cannot be resolved. The compiler suggests the
closest name it knows and offers to write it for you.

## Corrected

```ki corrected
fn main() { print(1) }
```

## Erroneous example

```ki erroneous
fn main() { let x = x }
```

The `x` in the initializer is not the variable that this `let` is binding: the variable exists
only after the statement. The compiler points at the `let` and explains the rule.

## Corrected

```ki corrected
fn main() { let x = 1 }
```
