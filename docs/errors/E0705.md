# E0705: wrong number of sub-patterns

A constructor pattern names one pattern for each field of the constructor: `Rect(w, h)` for a `Rect`
with two fields. Fewer or more would leave a field with no pattern, or a pattern with no field, and Ki
does not guess which. A constructor that has no fields is written with no parentheses.

The message says how many fields the constructor has and how many patterns the pattern names, and the
primary label, on the whole pattern, says it again: `1 sub-pattern`. A secondary label points at the
declaration of the constructor, `` `Rect` is declared here``, when it is in the same file. The help writes
the pattern with a `_` for each field, `` write `Rect(_, _)` ``, and when the pattern is on one line the
compiler offers the edit that replaces the whole of it with that text. The edit does not keep the patterns
that were written, because which of them goes with which field is not something it can tell: it is the
shape of the answer, and the variables go back where they belong. A constructor with no fields has its own
message, `` `None` has no fields``, and the help writes the name alone. The sub-patterns of a pattern that
does not fit are still bound, so their variables are not also unknown names.

## Erroneous example

```ki erroneous
type Shape { Circle(Float), Rect(Float, Float), Dot }
fn area(s: Shape) -> Float {
  match s {
    Circle(r) => r * r * 3.0
    Rect(w) => w
    Dot => 0.0
  }
}
fn main() {}
```

`Rect` has two fields and the pattern names one. The help says ``write `Rect(_, _)` `` and the edit does.

## Corrected

```ki corrected
type Shape { Circle(Float), Rect(Float, Float), Dot }
fn area(s: Shape) -> Float {
  match s {
    Circle(r) => r * r * 3.0
    Rect(w, h) => w * h
    Dot => 0.0
  }
}
fn main() {}
```

## Erroneous example

```ki erroneous
type Shape { Circle(Float), Dot }
fn area(s: Shape) -> Float {
  match s {
    Circle(r) => r * r * 3.0
    Dot(n) => 0.0
  }
}
fn main() {}
```

`Dot` has no fields, so the message says that, and the help writes `Dot`.

## Corrected

```ki corrected
type Shape { Circle(Float), Dot }
fn area(s: Shape) -> Float {
  match s {
    Circle(r) => r * r * 3.0
    Dot => 0.0
  }
}
fn main() {}
```
