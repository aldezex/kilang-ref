# E0406: unknown type

A type is written after the `:` of a parameter or of a `let`, or after the `->` of a function, and it
starts with a capital letter. It stands for a type that the program declares with `type` (in the file,
or `pub` in the standard library) or for one of the four that Ki has built in: `Int`, `Float`, `Bool`
and `()`. Any other name that starts with a capital letter, such as `Double` or `String`, is not a type
in scope. A constructor is not one either: it is a value, and `Circle` after a `:` is this error. (A
name that starts with a lowercase letter is not read as a type at all: that is E0201.)

The primary label is on the name and says `not a type in this scope`. When a name is spelled almost
like a type in scope, built in or declared, the compiler asks whether it was meant and offers the edit
that writes it. The mistake is reported once, where the name is written. What has that type is taken for
something that is already wrong, so a use of it adds no error of its own.

## Erroneous example

```ki erroneous
fn both(a: Bool, b: Bol) -> Bool { a && b }
fn main() { print(1) }
```

`Bol` is not a type, but it is one letter away from `Bool`, and the help says so: ``did you mean `Bool`?``.
The edit replaces the name. Nothing is said about `a && b`: `b` has a type that is already wrong.

## Corrected

```ki corrected
fn both(a: Bool, b: Bool) -> Bool { a && b }
fn main() { print(1) }
```

## Erroneous example

```ki erroneous
type Shape { Circle(r: Float) }
fn area(s: Shap) {}
fn main() {}
```

The types the program declares are candidates too: `Shap` is one letter away from `Shape`.

## Corrected

```ki corrected
type Shape { Circle(r: Float) }
fn area(s: Shape) {}
fn main() {}
```

## Erroneous example

```ki erroneous
fn main() { let a: Double = 1 }
```

`Double` is not like any type in scope, so there is no question. The `1` is not compared with `Double`:
a type that is not there cannot disagree with it.

## Corrected

```ki corrected
fn main() { let a: Int = 1 }
```
