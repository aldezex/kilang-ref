# E0406: unknown type

A type is written after the `:` of a parameter or of a `let`, or after the `->` of a function, and it
starts with a capital letter. Ki knows three types so far: `Int`, `Bool` and `()`. Any other name that
starts with a capital letter, such as `Float` or `String`, is not one of them. (A name that starts with a
lowercase letter is not read as a type at all: that is E0201.)

The primary label is on the name and says `not a type Ki knows`; the note lists the types Ki knows.
When a name is spelled almost like one of them, the compiler asks whether it was meant and offers the
edit that writes it. The mistake is reported once, where the name is written. What has that type is
taken for something that is already wrong, so a use of it adds no error of its own.

## Erroneous example

```ki erroneous
fn both(a: Bool, b: Bol) -> Bool { a && b }
fn main() { print(1) }
```

`Bol` is not a type, but it is one letter away from `Bool`, and the help says so: ``did you mean `Bool`?``.
The edit replaces the name. Nothing is said about `a && b`: `b` has a type that is already wrong.

## Corrected

```ki corrected
fn both(a: Bool, b: Bool) -> Bool { a && b }
fn main() { print(1) }
```

## Erroneous example

```ki erroneous
fn main() { let a: Float = 1 }
```

`Float` is not like any type Ki knows, so there is no question, and the note is what the compiler has
to say. The `1` is not compared with `Float`: a type that is not there cannot disagree with it.

## Corrected

```ki corrected
fn main() { let a: Int = 1 }
```
