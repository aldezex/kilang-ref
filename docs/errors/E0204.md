# E0204: expression is nested too deeply

Parentheses (of an expression, a tuple, or a tuple type), call arguments, the values of the fields of a
record literal, prefix operators, the parts of an `if` and blocks may nest at most 256 levels deep
inside one another. The parser reads each level with a call of its own, and so does
every later pass, so the limit protects the compiler from a file made to exhaust its stack.

The compiler reports the first level past the limit, 257, and skips the rest of the statement. The title
says what is too deep, an expression or (`type is nested too deeply`) a tuple type, and the help says how
to split it: with `let` bindings for an expression, with `type` aliases for a tuple type.

```ki erroneous
  ((((((((((((((((((((((((((((((((((((((((((((((((((((((((((((
  (((((((((((((((((1
  ))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))
  ))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))
  ))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))
  ))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))
  ))))))))))))))))) }
```

The 257th parenthesis is the mistake. Split the expression into several statements with `let`. The
example is written on several lines to be read: inside parentheses a line break is only a space.

## Corrected

```ki corrected
fn main() {
  let a = (1 + 2)
  print(a)
}
```
