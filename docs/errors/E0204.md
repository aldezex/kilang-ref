# E0204: expression is nested too deeply

Parentheses, call arguments, prefix operators, the parts of an `if` and blocks may nest at most
256 levels deep inside one another. The parser reads each level with a call of its own, and so does
every later pass, so the limit protects the compiler from a file made to exhaust its stack.

The compiler reports the first level past the limit, 257, and skips the rest of the statement.

```ki erroneous
  ((((((((((((((((((((((((((((((((((((((((((((((((((((((((((((
  ((((((((((((((((((((((((((((((((((((((((((((((((((((((((((((
  (((((((((((((((((1
  ))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))
  ))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))
  ))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))
  ))))))))))))))))))))))))))))))))))))))))))))))))))))))))))))
  ))))))))))))))))) }
```

The 257th parenthesis is the mistake. Split the expression into several statements with `let`. The
example is written on several lines to be read: inside parentheses a line break is only a space.

## Corrected

```ki corrected
fn main() {
  let a = (1 + 2)
  print(a)
}
```
