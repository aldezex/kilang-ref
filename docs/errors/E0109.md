# E0109: float literal is out of range

A `Float` is a 64-bit floating-point number. The largest finite one is 1.7976931348623157e308,
and a literal whose value is larger does not fit. (A literal that is too small is not an error: it
is rounded to 0, as in Go.)

The literal still counts as a number, with the value 0.

The examples bind the literal with a `let`: `print` takes an `Int`, so `print(1e300)` would be a
mismatch of types (E0401), and the one that prints a `Float` is `printFloat`.

## Erroneous example

```ki erroneous
fn main() { let x = 1e999 }
```

The exponent is too large. The compiler states the limit and suggests a smaller exponent. When the
literal has no exponent, or its digits alone are already too large, it suggests a smaller value instead.

## Corrected

```ki corrected
fn main() { let x = 1e300 }
```

The exponent is within range.
