# E0402: wrong number of arguments

A call supplies one argument for each parameter of the function it calls, no more and no fewer. Ki has
no default values and no optional parameters, so a function that takes two arguments is called with
two.

The primary label is on the argument list, from the `(` to the `)`, so that it has a width even when
there are no arguments, and says `supplied here`. When the function is one of the program, a secondary
label shows where it is declared, and a note writes the types of its parameters, such as
`` `area` takes `(Int, Int)` ``. The compiler offers no help and no edit: whether an argument is missing
or one is too many, and which, is for the author to say. The arguments are not compared with the
parameters, because with the wrong count there is no telling which goes with which; they are still
checked on their own.

## Erroneous example

```ki erroneous
fn area(w: Int, h: Int) -> Int { w * h }
fn main() { print(area(3)) }
```

`area` takes two arguments and the call supplies one. The label on `(3)` says `supplied here`, the label
on the name `area` in its definition says `` `area` is declared here ``, and the note gives the
parameters: `` `area` takes `(Int, Int)` ``.

## Corrected

```ki corrected
fn area(w: Int, h: Int) -> Int { w * h }
fn main() { print(area(3, 4)) }
```

## Erroneous example

```ki erroneous
fn double(x: Int) -> Int { x * 2 }
fn main() { print(double(1, 2)) }
```

The same mistake the other way round: one parameter and two arguments. The list `(1, 2)` is the
primary label and the note says `` `double` takes `(Int)` ``.

## Corrected

```ki corrected
fn double(x: Int) -> Int { x * 2 }
fn main() { print(double(1)) }
```

## Erroneous example

```ki erroneous
fn main() { print(1, 2) }
```

`print` is a function of the standard library, which lives in another file, so there is no label where
it is declared: a label can only be drawn under the primary one when both are in the same file. The
note is there all the same: `` `print` takes `(Int)` ``.

## Corrected

```ki corrected
fn main() { print(1) }
```
