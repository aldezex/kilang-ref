# E0103: unterminated block comment

A block comment starts with `/*` and ends with `*/`. Block comments nest: every `/*` inside a
comment opens a new level, and every `*/` closes one. The file ended while a comment was still
open, so everything after the opening `/*` was read as comment.

The compiler points at the `/*` that opened the outermost open comment, not at the end of the file.

## Erroneous example

```ki erroneous
fn main() { print(1) }
/* the rest of the file
```

The comment starts on the second line and never closes. The compiler suggests closing it with `*/`
and offers to write it at the end of the file, once for every level that is still open. If the
file ends in a `/` that is part of the comment's text (a path or a URL), the edit starts with a
space, so that this `/` and the `*` of the edit are not read as the start of another comment.

## Corrected

```ki corrected
fn main() { print(1) }
/* the rest of the file */
```
