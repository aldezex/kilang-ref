# E0304: `#[extern]` is only allowed in the standard library

A function marked with `#[extern]` has no body: its code is supplied by the runtime, and only the
standard library declares such functions. A program calls them through the prelude (`print` is
one) and cannot declare its own.

The compiler points at the attribute, from the `#` to the `]`, and suggests removing it. For an
attribute on one line it offers that edit, except when the function has no body, as in the example
below: without the attribute such a function is an error of its own, so the help asks for the body
too and the compiler offers no edit.

## Erroneous example

```ki erroneous
#[extern("ki_print_int")]
fn show(x: Int)
fn main() {}
```

The function `show` is declared as an extern function in a program.

## Corrected

```ki corrected
fn show(x: Int) {}
fn main() {}
```

With the attribute removed the function needs a body, like any other.
