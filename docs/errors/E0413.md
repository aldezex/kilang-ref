# E0413: no such element

An element of a tuple is read with `.0`, `.1`… The first is `.0`, and a tuple of two has `.0` and `.1`.
A number that is past the last element, or a `.0` on something that is not a tuple, has no element to
read.

The primary label is on the number and says which ones exist: `only `.0` and `.1` exist` for a tuple
of two, `only `.0`, `.1` and `.2` exist` for three, and `only `.0` to `.7` exist` from four on. The
message and the label show the number as it is written, so `t.99999999999` says `99999999999` and not
a number that was cut to fit. For a type that is not a tuple the message is `` `Int` has no element `0` ``,
the label says `not a tuple` and the note says `only a tuple has elements `.0`, `.1`…`. There is no
help.

## Erroneous example

```ki erroneous
fn main() {
  let t = (1, true)
  print(t.2)
}
```

`t` is an `(Int, Bool)`: it has `.0` and `.1`.

## Corrected

```ki corrected
fn main() {
  let t = (1, true)
  print(t.0)
}
```

## Erroneous example

```ki erroneous
fn main() {
  let n = 5
  print(n.0)
}
```

An `Int` is not a tuple, so it has no elements; the note says what does.

## Corrected

```ki corrected
fn main() {
  let n = (5, 6)
  print(n.0)
}
```
