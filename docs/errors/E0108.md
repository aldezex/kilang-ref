# E0108: invalid character literal

A character literal is written between single quotes and holds exactly one character, either as it
is (`'a'`) or as an escape (`'\n'`). The compiler rejects a literal that holds none, one that holds
more than one, and one that is not closed on its line.

The mistake is reported once for the whole literal, and the literal still counts as a character, so
it is not reported again where it is used.

Strings and characters cannot be used in expressions yet, so, for now, `ki check` also reports
E0201 for the literal of each example below as a whole, besides the mistake inside it. The fences
that say `also=E0201` are the sign of that: when the compiler reads strings and characters in
expressions, those words and this paragraph go away.

## Erroneous example

```ki erroneous also=E0201
fn main() { print('') }
```

There is nothing between the quotes. The compiler asks for the character; it offers no edit.

## Corrected

```ki corrected also=E0201
fn main() { print('a') }
```

The character is written between the quotes.

## Erroneous example

```ki erroneous also=E0201
fn main() { print('ab') }
```

Two characters are text, and text is written in double quotes. The compiler suggests the string and offers to replace the literal with it. If the text is longer than 80 bytes, the help does not repeat it and only says to write a string; the edit still replaces the whole literal.

## Corrected

```ki corrected also=E0201
fn main() { print("ab") }
```

The text is a string, in double quotes.

## Erroneous example

```ki erroneous also=E0201
fn main() {
  let c = 'a
}
```

The literal runs to the end of the line without a closing quote. The compiler suggests closing it and offers to write the quote at the end of the line. It does so only when exactly one character follows the opening quote: after `'ab` a quote would make a literal of two characters, and after a lone `'` one of none, which are still errors, so there the compiler offers no edit.

## Corrected

```ki corrected also=E0201
fn main() {
  let c = 'a'
}
```

The closing quote is at the end of the line.
