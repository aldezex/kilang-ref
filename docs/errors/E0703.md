# E0703: or-pattern binds a name in one alternative only

An or-pattern, `Circle(r) | Square(r)`, matches a value if any of its alternatives does, and the guard
and the body of the arm run whichever one it was. They can use a variable of the pattern only if every
alternative binds it: a name that just some of them bind would stand for nothing when another matched.
So all the alternatives of a `|` bind the same names.

The primary label is on the first alternative that does not bind the name, `` `r` is not bound here``,
and the secondary label on the first alternative that does, `` `r` is bound here``, whichever of the two
comes first. A note says the rule: every alternative of `|` binds the same names, so the body can use
them. There is no help and no edit: whether the name belongs in the other alternatives or in none is not
something the program says. The error is one for each name, however many alternatives lack it. The name
stays bound for the arm, so a use of it in the body is not also an unknown name, and the arm is checked
as if the or-pattern had bound it everywhere.

## Erroneous example

```ki erroneous
type Shape { Circle(Float), Square(Float), Dot }
fn size(s: Shape) -> Float {
  match s {
    Circle(r) | Dot => 1.0
    Square(x) => x
  }
}
fn main() {}
```

`r` is bound by `Circle(r)` and not by `Dot`. The label is on `Dot`, the alternative that lacks it, and
the secondary label on `Circle(r)`.

## Corrected

```ki corrected
type Shape { Circle(Float), Square(Float), Dot }
fn size(s: Shape) -> Float {
  match s {
    Circle(r) | Square(r) => r
    Dot => 0.0
  }
}
fn main() {}
```

## Erroneous example

```ki erroneous
type Shape { Circle(Float), Square(Float), Dot }
fn size(s: Shape) -> Float {
  match s {
    Dot | Circle(r) => r
    Square(x) => x
  }
}
fn main() {}
```

The same mistake with the alternatives the other way round, and a body that uses `r`. The label is on
`Dot`, which comes first and lacks the name, and the `r` in the body is not reported as unknown.

## Corrected

```ki corrected
type Shape { Circle(Float), Square(Float), Dot }
fn size(s: Shape) -> Float {
  match s {
    Dot => 0.0
    Circle(r) | Square(r) => r
  }
}
fn main() {}
```
