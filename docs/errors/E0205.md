# E0205: expression chain is too long

One expression may hold at most 1024 operators and calls. The parser keeps a count while it reads
an expression, and every later pass recurses once per level of a chain, so the limit protects the
compiler's stack: a file with a chain of a hundred thousand terms cannot exhaust it.

The compiler reports the 1025th operator or call and skips the rest of the statement.

The expression has 1025 additions, and the 1025th is the mistake. Split the expression into several
statements with `let`. The example is written on several lines to be read: a line that ends in `+`
does not end the statement.

## Corrected

```ki corrected
fn main() {
  let a = 1 + 1
  print(a + 1)
}
```
