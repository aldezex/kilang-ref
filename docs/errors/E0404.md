# E0404: `main` must be `fn main()`

A program starts at its function `main`. Ki calls it with no arguments and expects nothing back, so
its type is `() -> ()`: no parameters, and the return type `()` that a function without `->` has
anyway. A `main` with parameters has nothing to receive them from, and a value that `main` returns has
nobody to receive it.

The primary label is on the name `main` and says what is wrong with the signature:
`` declared here with 2 parameter(s) ``, `` declared here returning `Int` ``, or both at once. A note
repeats the rule, and the help says what to remove: the parameters, the `-> Int`, or the two together.
For a signature written on one line the compiler also offers the edit: it writes `()` over the
parameter list, from its `(` to its `)`, and deletes the return clause, the blanks just before the `->`
included (a comment between the `)` and them stays). When the signature runs over several lines, or
when only one of two things could be edited, there is no edit and the help is all there is. `-> ()` is
not a mistake, since it says what the default says.

The edit removes the parameters but not the uses of them: if the body reads a parameter, it needs a
value from somewhere else, as in the corrected example below.

## Erroneous example

```ki erroneous
fn main(count: Int) {
  print(count)
}
```

`main` declares a parameter, and nobody can supply it. The label on `main` says
`` declared here with 1 parameter(s) ``, and the help says `remove the parameters`.

## Corrected

```ki corrected
fn main() {
  let count = 3
  print(count)
}
```

The value the body needed is now defined inside it.

## Erroneous example

```ki erroneous
fn main() -> Int {
  print(1)
  0
}
```

`main` returns an `Int`. The body agrees with its own signature, so this is the only error; the label
says `` declared here returning `Int` `` and the help says `` remove `-> Int` ``.

## Corrected

```ki corrected
fn main() {
  print(1)
}
```

## Erroneous example

```ki erroneous
fn main(n: Int) -> Int { n }
```

Both are wrong, so the label, the help and the edit say both: the label is
`` declared here with 1 parameter(s) and returning `Int` ``, the help is
`` remove the parameters and `-> Int` ``, and there are two edits, one for each.

## Corrected

```ki corrected
fn main() { print(42) }
```
