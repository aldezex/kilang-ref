# E0102: control character in source

Besides the tab, the line feed and the carriage return, Ki does not allow an ASCII control
character (a byte below `0x20`, or `0x7F`) in the source: most editors do not show them, so they
are invisible mistakes. The compiler reports the first one it finds.

## Erroneous example

The block is written as a Go string because a text file of this repository cannot hold the control character itself.

```ki erroneous escaped
"fn main() { print(1) }\x01\n"
```

The byte `0x01` follows the function. The compiler suggests deleting it and offers that edit. Inside
a string, where a control character is sometimes wanted, it can be written as the escape `\u{1}`.

## Corrected

```ki corrected
fn main() { print(1) }
```

With the byte deleted, the file is plain text.
