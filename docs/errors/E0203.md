# E0203: comparison operators cannot be chained

Comparison operators do not associate: `a < b < c` is neither `(a < b) < c` nor `a < (b < c)`,
and neither would mean what it does in mathematics. Write each comparison on its own and join them
with `&&`.

The compiler points at the second operator and, as a secondary label, at the first. When the three
operands are single tokens it writes the suggestion with them, and when the middle operand is a
single token it offers the edit that turns `a < b < c` into `a < b && b < c`.

## Erroneous example

```ki erroneous
fn main() { print(1 < 2 < 3) }
```

The edit inserts `&& 2 ` before the second `<`.

## Corrected

```ki corrected
fn main() { print(1 < 2 && 2 < 3) }
```
