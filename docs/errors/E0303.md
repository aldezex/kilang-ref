# E0303: no `main` function

`ki run` starts a program at its function `main`, and the file has none. `ki check` does not need
one, because a file of functions that other files use is a fine thing to check, so only the command
that has to start the program reports the error, and only when the file has no other error: a
program that is wrong in another way gets those errors first.

The compiler points at the start of the file, since no line of it is to blame, and says that the file
has no `fn main()`. A note says why `ki run` needs one, and the help says what to add. There is no
edit: where `main` goes in the file, and what it does, is not for the compiler to say.

A function with another name is not a `main`: a file whose only function is `fn mian()` still has no
`fn main()`.

## Erroneous example

```ki erroneous run
fn helper() -> Int { 1 }
```

The file defines a function but nothing starts the program. The label sits on the first character of
the file, at line 1, column 1.

## Corrected

```ki corrected run
fn helper() -> Int { 1 }

fn main() {
  print(helper())
}
```

`main` takes no parameters and returns `()`, like the one that E0404 asks for, and the program now
runs: it prints `1`.
