# E0107: malformed number literal

Two things make a number literal malformed. A digit separator `_` may stand between digits, but
a run of digits may not end in one: `1_000_` is an error. And a hexadecimal or binary literal needs
digits after its prefix: `0x` and `0b` alone are errors.

The literal still counts as a number, with the value 0, so the mistake is not reported again where
the number is used.

## Erroneous example

```ki erroneous
fn main() { print(1_000_) }
```

The trailing `_` is the mistake. The compiler suggests removing it and offers that edit.

## Corrected

```ki corrected
fn main() { print(1_000) }
```

## Erroneous example

```ki erroneous
fn main() { print(0x) }
```

There is nothing after the prefix. The compiler asks for the digits and shows what they look like; it offers no edit, because only you know the number.

## Corrected

```ki corrected
fn main() { print(0xFF) }
```
