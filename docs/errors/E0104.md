# E0104: unexpected character

The source has a character that Ki does not use anywhere. Identifiers and operators are ASCII,
so a letter with an accent, a typographic quote or an emoji outside a string or a comment is an
error; so are the ASCII symbols that Ki has no use for, such as `$` and `@`.

The compiler reports the character, skips it and goes on reading, so one stray character does not
hide the mistakes after it.

## Erroneous example

```ki erroneous
fn main() { print(1) $ }
```

The `$` has no meaning here. The compiler suggests removing it and offers that edit.

## Corrected

```ki corrected
fn main() { print(1) }
```

## Erroneous example

```ki erroneous
fn café() {}
```

A letter that is not ASCII gets the same help and an extra note: identifiers use only the ASCII letters, the digits and `_`.

## Corrected

```ki corrected
fn cafe() {}
```
