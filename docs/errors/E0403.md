# E0403: cannot call a value that is not a function

Only a function can be called. The callee of `x(1)` has the type of `x`, and if that type is `Int`,
`Bool` or `()` there is nothing to call. A function that is held in a variable or passed as a parameter
can be called, and so can a parameter whose type is not written yet: the call then tells the compiler
that it is a function.

The primary label is on the callee and says `not a function`, and the message gives its type. When the
callee is a variable, a secondary label shows where it is bound, such as `` `n` is bound here ``. The
compiler offers no help and no edit, because what the author meant by the call is not something it can
guess. The arguments are still checked on their own.

## Erroneous example

```ki erroneous
fn main() {
  let n = 3
  n(1)
}
```

`n` is an `Int`. The label on `n` in `n(1)` says `not a function`, the message says
``cannot call a value of type `Int` ``, and the label on the `n` of the `let` says `` `n` is bound here ``.

## Corrected

```ki corrected
fn main() {
  let n = 3
  print(n)
}
```

## Erroneous example

```ki erroneous
fn check(flag: Bool) { flag() }
fn main() { }
```

A parameter can be the value that is called wrongly. Its type is written, `Bool`, so the compiler knows
that it is not a function, and the secondary label is on the parameter.

## Corrected

```ki corrected
fn check(flag: Bool) { if flag { print(1) } }
fn main() { }
```
