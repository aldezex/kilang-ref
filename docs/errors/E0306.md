# E0306: unknown constructor

A name that starts with an uppercase letter is used in an expression and nothing declares it. In Ki a
name that starts in uppercase can only be a constructor, one of the variants of a `type`, so this is
not an unknown name (E0301, which is for the names of functions and variables) but an unknown
constructor. The type itself is not a value, so the name of a type used as an expression is this
error too: the types live in a name space of their own, which only a type annotation looks in.

The primary label is on the name and says `not a constructor in this scope`. There is no secondary
label and no note. If a constructor that is visible is spelled almost like the name, the compiler asks
whether it was meant and offers the edit that writes it; a function, a variable or a type is never
suggested, because none of them could stand where a constructor stands. With no such constructor there
is no help at all. The arguments of the call are still checked on their own, and nothing is said about
the place where the value is used: a constructor that does not exist has the error type, which fits
everywhere, so one mistake is one error.

## Erroneous example

```ki erroneous
type Shape { Circle(r: Float) }
fn main() { let s = Circl(1.0) }
```

`Circl` is declared nowhere, and `Circle` is one letter away: the help says ``did you mean `Circle`?``
and the edit writes it.

## Corrected

```ki corrected
type Shape { Circle(r: Float) }
fn main() { let s = Circle(1.0) }
```

## Erroneous example

```ki erroneous
type Shape { Circle(r: Float) }
fn main() { let s = Shape }
```

`Shape` is a type, not a value: only `Circle` can be written where a value of that type is wanted. No
visible constructor is spelled like `Shape`, so there is no help.

## Corrected

```ki corrected
type Shape { Circle(r: Float) }
fn main() { let s = Circle(1.0) }
```
